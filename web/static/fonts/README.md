# Шрифты сайта

* Manrope и Unbounded — переменные шрифты, лицензия SIL Open Font License 1.1 (свободное использование и встраивание).
* Источник: Google Fonts (fonts.gstatic.com), подмножества «cyrillic» и «latin», формат woff2. Скачано 2026-10-24.
* Подключены в `web/static/css/main.css` через `@font-face` с `unicode-range`; других подмножеств (греческий, вьетнамский,
  расширенная латиница и кириллица) нет — для них браузер возьмёт системный шрифт.
